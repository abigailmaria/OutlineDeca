# OutlineDeca

Builds customizable user interfaces for machine learning models using a web-based visual editor.

With OutlineDeca, you get a lightweight tool that stays out of your way.

**What you get**

- Builds customizable user interfaces for
- machine learning models using a
- web-based visual editor

## Key Features

- Builds customizable user interfaces for
- machine learning models using a
- web-based visual editor

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/OutlineDeca.git`
2. `cd OutlineDeca`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
